# Запуск і перевірка — Zaryad

## Запуск

1. Відкрити `Zaryad.xcodeproj` у Xcode.
2. Дочекатися, поки Xcode підтягне пакет Firebase (Swift Package Manager).
3. Обрати схему `Zaryad` і будь-який iPhone-симулятор, натиснути **Run**.

Власний сервер не потрібен: усі ключі вже в репозиторії.

## Джерело даних

- **Open Charge Map API** — зарядні станції (`GET https://api.openchargemap.io/v3/poi`).
- **Firebase** (проєкт `zaryad-12303`) — Auth (Email/Password) для акаунтів і Firestore (REST) для обраного.

## Перший запит

1. Застосунок відкривається на головному екрані — **Карта**.
2. На запит доступу до локації натиснути **Allow While Using App**.
3. Карта центрується на вашій локації, і йде перший запит до Open Charge Map — на карті з'являються піни станцій.

> Без доступу до локації карта відкриється на Києві. У симуляторі локацію можна задати: **Features → Location**.

## Перевірка станів

| Стан | Як отримати |
|---|---|
| Завантаження | Зсунути карту — зверху «Пошук станцій…» |
| Дані | Піни станцій на карті |
| Порожньо | Зсунути карту туди, де немає станцій (море) — «Поруч немає станцій» |
| Помилка | Вимкнути інтернет на Mac і зсунути карту — тост і кнопка «Повторити» |

Обране й профіль: **Профіль → Створити акаунт**, далі на карті станція → **Детальніше → В обране**; станція з'явиться в табі **Обране**.
